# Gundam Assemble tools

Fan-made helper apps for the Gundam Assemble tabletop game (rules: Official Core Rulebook v1.2).

| File | What it is |
|---|---|
| `squad-tracker.html` | Squad Tracker + Attack Roll: unit HP, upgrades, status, RWS tokens, VP/Phase, and an attack-roll calculator with dice animation and exact odds. Phone first; iPad landscape shows both side by side. |
| `scoreboard.html` | Manual store scoreboard: names, VP, Phase, Round, flip mode for two players across a table, display mode. |

Open either file in a browser. Outside its Claude artifact, the tracker saves on the device only (no shared unit list); the scoreboard works fully offline.

Card data comes from the Bandai unit list. Not affiliated with Bandai.
